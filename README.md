# Spring boot + Spring Cloud + Vue + Element的权限管理系统

| 模块       | 端口   | 功能                                                                 |
|----------|------|--------------------------------------------------------------------|
| admin    | 8000 | 用户、角色、菜单、部门管理功能                                                    |
| backup   | 8001 | 数据库备份功能                                                            |
| monitor  | 8002 | 系统监控功能                                                             |
| consumer | 8003 | 消费者功能                                                              |
| common   | -    | 公共配置和工具类                                                           |
| core     | -    | 核心组件（异常处理、统一返回结果、统一异常处理、统一日志处理、统一权限处理、统一参数处理、统一缓存处理、统一分页处理、统一文件处理） |
| producer | 8006 | 生产者功能                                                              |
